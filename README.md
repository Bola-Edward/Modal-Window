# Modal Window

A lightweight, responsive modal window demo built with HTML, CSS, and vanilla JavaScript. Open one of three dialogs to see its content update based on the button you choose.

## Features

- Three buttons to open the modal
- Dynamic heading and message based on the selected button
- Blurred backdrop overlay
- Close using the close button, clicking the overlay, or pressing `Escape`
- Smooth fade and scale transitions, with reduced-motion support
- Accessibility support with dialog ARIA attributes, visible keyboard focus, and focus management

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Prettier for code formatting
